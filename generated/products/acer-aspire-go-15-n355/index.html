Our Review

The Aspire Go 15 is for people who need Windows and a big screen without spending much. The 15.6-inch 1920×1080 IPS display is comfortable for documents and video, and the Intel Core 3 N355 handles email, web browsing, and streaming. Expectations matter here: 8GB of memory and 128GB of storage are minimal, so it's best for light, focused use. It ships in Windows 11 S mode, which you can switch off for free if you need to install apps outside the Microsoft Store.
